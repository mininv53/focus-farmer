# ASSETS.md — drop your own art and audio here

The MVP ships with **procedural low-poly 3D crops** built from primitive
Three.js geometry (`components/garden/crop-3d.tsx`) and **synthesized audio**
generated by `lib/audio/synth.ts`. Replace either by dropping files into the
paths below — code will pick them up automatically once the loader hooks
described in this doc are wired up.

## Conventions

- 3D models are **glTF Binary** (`.glb`), Y-up, ~5–500 triangles per part,
  scale roughly **1 unit = 1 plot tile** (about 1.4 m).
- All textures inside the glTF must be **baseColor only**, sRGB, no normal
  maps, no PBR — we want a flat low-poly look.
- Crop models are placed at origin `(0, 0, 0)`; the scene shifts them onto
  plots itself.
- Audio is `.mp3`, mono, 44.1 kHz, **−14 LUFS** target loudness, less than
  500 ms for one-shots and looping for ambient.

## Crop 3D models

Drop these files into `public/models/crops/`. Each species needs **one model
per growth stage** (1 = sprout, 2 = leafing, 3 = budding, 4 = mature) so the
plant can morph as it ages. Stage 0 is invisible (bare soil).

Filenames follow the pattern `<species>-<stage>.glb`.

| Filename                                          | Description                                                      |
| ------------------------------------------------- | ---------------------------------------------------------------- |
| `public/models/crops/carrot-1.glb` … `-4.glb`     | Carrot stages (leafy crown above, root cone visible at stage 4). |
| `public/models/crops/wheat-1.glb` … `-4.glb`      | Wheat stages (tall stalk, golden head at stage 4).               |
| `public/models/crops/strawberry-1.glb` … `-4.glb` | Strawberry stages (low bush, red berries at stage 4).            |
| `public/models/crops/tomato-1.glb` … `-4.glb`     | Tomato stages (low bush, red clustered fruit at stage 4).        |
| `public/models/crops/pumpkin-1.glb` … `-4.glb`    | Pumpkin stages (vine pad, big round orange at stage 4).          |
| `public/models/crops/sunflower-1.glb` … `-4.glb`  | Sunflower stages (tall stalk, yellow head at stage 4).           |
| `public/models/crops/grape-1.glb` … `-4.glb`      | Grape stages (low vine, purple cluster at stage 4).              |
| `public/models/crops/pineapple-1.glb` … `-4.glb`  | Pineapple stages (small palm, spiky yellow fruit at stage 4).    |

Once you drop a `.glb` into `public/models/crops/`, replace the
species-shape switch in `components/garden/crop-3d.tsx` with a `useGLTF`
load that points at the matching stage filename. Keep the procedural
geometry as a fallback when the model is missing.

## Plot tiles

Drop into `public/models/tiles/` if you want richer plot art (e.g. a
wood-framed planter box).

| Filename                             | Description                                               |
| ------------------------------------ | --------------------------------------------------------- |
| `public/models/tiles/plot-empty.glb` | Empty plot box (replaces the procedural light-soil mesh). |
| `public/models/tiles/plot-soil.glb`  | Plot with darker soil where a crop is planted.            |

## Audio

Drop into `public/audio/`.

| Filename                       | Length | Description                                                                 |
| ------------------------------ | ------ | --------------------------------------------------------------------------- |
| `public/audio/start.mp3`       | <1s    | Soft chime when a session starts.                                           |
| `public/audio/complete.mp3`    | 1–2s   | Warm three-note jingle when a session completes.                            |
| `public/audio/plant.mp3`       | <1s    | Soft "shhk" when seeds are planted.                                         |
| `public/audio/harvest.mp3`     | <1s    | Crisp pluck when a crop is harvested.                                       |
| `public/audio/click.mp3`       | <0.2s  | Tiny UI click for buttons (subtle).                                         |
| `public/audio/ambient-day.mp3` | 30–90s | Looping cozy ambient: light wind, soft chimes, optional birds. Volume-safe. |

## Open-source-friendly 3D packs (suggested seeds)

If you want **CC0** placeholders that are nicer than the procedural ones:

- [Kenney — Foods Kit](https://kenney.nl/assets/food-kit) (low-poly fruits/veg)
- [Quaternius — Stylized Foods](https://quaternius.com/packs/stylizedfood.html)
- [Quaternius — Ultimate Stylized Nature](https://quaternius.com/packs/ultimatestylizednature.html)
- [Poly Pizza](https://poly.pizza) (search "carrot", "tomato", "pumpkin")
- [Kenney — UI Audio](https://kenney.nl/assets/ui-audio)

These are all **Public Domain / CC0** so you can ship them without crediting.
Just rename the files to the conventions above and drop them in.
